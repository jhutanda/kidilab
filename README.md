# KIDILAB - AI-Powered Learning Hub for Kids 🎨🧠

KIDILAB is a vibrant, interactive, and AI-powered learning platform designed specifically for children. It offers a suite of educational tools and games that make learning fun, engaging, and creative.

## 🌟 Features

### 🎨 Art Studio (New!)
A comprehensive image editor and coloring book for kids.
- **10 Coloring Templates**: Animals, Nature, Objects, and Shapes.
- **Advanced Tools**: Brush, Eraser, Fill Bucket, Line Tool, and Spray Paint.
- **Custom Shapes**: Circle, Square, Star, Heart, and Smiley Face.
- **Creative Controls**: 16-color palette, 8 background colors, adjustable brush sizes, and opacity settings.
- **Work Flow**: Full Undo/Redo history and Save as PNG functionality.

### 📝 AI Poem Generator
Generate beautiful rhymes for kids using AI.
- Create unique poems about any topic.
- Vibrant display cards with child-friendly styling.

### 🔡 Alphabet Learning
Explore the alphabet with interactive cards and audio.
- Toggle between uppercase and lowercase.
- Visual examples for every letter.

### 🔢 Numbers Learning
Learn numbers from 1 to 100 with organized tabs.
- Interactive number grid.
- Colorful and intuitive navigation.

### 🎮 Match the Letters Game
A fun drag-and-drop game to practice letter matching.
- Interactive baskets and floating letters.
- Regenerate button for endless practice.
- Voice-supported learning.

## 🚀 Tech Stack

- **Framework**: [React 18](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **AI Integration**: Custom AI wrappers for teaching and creative tasks.
- **Audio**: [ElevenLabs](https://elevenlabs.io/) for high-quality AI voices.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jhutanda/kidilab.git
   cd kidilab
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

## 📂 Project Structure

- `/src/features`: core components for Alphabet, Numbers, Art, and Games.
- `/src/components`: Reusable UI components (Buttons, Cards, Navbar, etc.).
- `/src/store`: Global state management with Zustand.
- `/src/lib`: API integrations and utilities.
- `/src/layouts`: Main page layout and navigation structure.
